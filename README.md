# Jean Amaral

I automate manual processes with software, from IoT hardware to mobile apps.
Today I work on quality and automation for vehicle cameras and GPS trackers
at INFLEET, in São Paulo, Brazil.

I build with AI agents in the terminal (Claude Code) and write my own skills
for them. I review everything before it ships.

## Projects

- [skills](https://github.com/jeanamaralsilva/skills): four open source agent
  skills that review UX, dependencies, code and tests of mobile apps.
  Every data row has a source.
- Hefesto (private): batch provisioning for vehicle cameras and GPS trackers,
  validated on real hardware. Electron, React, TypeScript, Elixir, Phoenix LiveView.
- Idiomia (private): app for language teachers with CEFR levels and Pix payments.
  React Native, Expo, Supabase.

## Stack

Elixir · TypeScript · React · React Native · SQL · n8n · Python
